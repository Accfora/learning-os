# Методический профиль курса: Основы российской государственности

Документ фиксирует требования к подготовке к семинарам, источниковую базу и стандарт оформления конспектов в рамках Karpathy-style Learning OS.

---

## 1. Источниковая база и приоритеты

1. **Базовый канонический источник:**
   * Учебное пособие под руководством А. А. Ларионова (иеромонаха Родиона): *«Основы российской государственности: учебное пособие для студентов естественно-научных и инженерно-технических специальностей»* (М.: Издательский дом «Дело» РАНХиГС, 2023).
   * Вся фактологическая основа, цивилизационные концепции (включая пентабазис, ценностное ядро, типологию мировоззрений) в первую очередь извлекаются непосредственно из данного учебника.
2. **Вторичные академические источники:**
   * Привлекаются только при отсутствии узкоспециализированного аспекта темы в учебнике Ларионова.
   * Опора на классическую отечественную социально-философскую, историческую и социологическую мысль с обязательным указанием первоисточника (*provenance*).

---

## 2. Стандарт формирования ответов к семинарам

1. **Строгая чистота предмета вопроса:**
   * Фокусировка строго по теме без ухода в смежные или абстрактные рассуждения.
   * Раскрытие сущности терминов, механизмов и взаимосвязей дается ёмко и доказательно, без водянистости («не на 10 листов»).
2. **Двухуровневая модель конспекта:**
   * **Уровень 1 (Каркас для тетради — Часть I):**
     * Страница тетради вмещает **~100 слов**.
     * Конспект каждого вопроса строго калибруется по объему: **~100 слов на вопрос (1 страница тетради)**.
     * Структурированная блочно-тезисная форма, оптимизированная для быстрого рукописного переписывания и мгновенного схватывания взглядом на занятии.
   * **Уровень 2 (Глубокий разбор для устного ответа — Часть II):**
     * Развёрнутый академический контекст, раскрытие концепций (Момджян, Дюркгейм, цивилизационный подход), формулировки и аргументы для уверенного ответа у доски и дискуссий с преподавателем.
