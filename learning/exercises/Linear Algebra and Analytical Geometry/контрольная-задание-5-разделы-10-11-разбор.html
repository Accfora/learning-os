База
Дано и базовые векторы варианта 3
Точки:
A(10; 9; −2),   B(−11; −12; 19),   C(−18; −5; 12),   D(3; 2; −9)
🗣️ Причинно-следственный фундамент:
Все 9 пунктов задачи сводятся к операциям над векторами рёбер. Вектор с началом в P₁ и концом в P₂ считается строго как координаты конца МИНУС координаты начала. Сразу выносим общие скалярные множители — это спасет от громоздкого умножения трёхзначных чисел!
AB = B − A = {-21; -21; 21} = 21·{-1; -1; 1} AC = C − A = {-28; -14; 14} = 14·{-2; -1; 1} AD = D − A = {-7; -7; -7} = -7·{1; 1; 1} BC = C − B = {-7; 7; -7} = 7·{-1; 1; -1} BD = D − B = {14; 14; -28} = 14·{1; 1; -2} CD = D − C = {21; 7; -21} = 7·{3; 1; -3}
💡 Маячок: Вектор = Конец минус Начало. Вынес коэффициенты (7, 14, 21) — упростил вычисления в 10 раз!
5.1
1) Скалярное произведение (AC, AD) и угол ABC
Дано: AC = {-28; -14; 14},   AD = {-7; -7; -7},   вершина угла — B.
🗣️ Причинно-следственное основание:
• Скалярное произведение в базисе — сумма произведений одноименных координат (следует из дистрибутивности и ортонормированности ортов).
• Угол ABC: его вершина — точка B! Значит, лучи исходят из B: нужны векторы BA и BC (если взять AB, угол вывернется на 180°).
• Косинус угла выражается из определения: (u, v) = |u|·|v|·cos φ ⇒ cos φ = (u, v) / (|u|·|v|).
📌 Академическое решение и вычисления:
1) (AC, AD) = (-28)·(-7) + (-14)·(-7) + 14·(-7) = 196 + 98 − 98 = 196.
2) Векторы: BA = -AB = {21; 21; -21} = 21·{1; 1; -1},   BC = 7·{-1; 1; -1}.
• Длины: |BA| = 21·√(1+1+1) = 21√3;   |BC| = 7·√(1+1+1) = 7√3.
• (BA, BC) = 21·7·(1·(-1) + 1·1 + (-1)·(-1)) = 147·(-1 + 1 + 1) = 147.
• cos ∠ABC = 147 / (21√3 · 7√3) = 147 / (147 · 3) = 1/3.
Ответ: (AC, AD) = 196;   ∠ABC = arccos(1/3)
💡 Маячок: Угол ABC — вершина B в центре! Берём лучи BA и BC, косинус = скалярное / (произведение длин).
5.2
2) Векторное произведение [AB, CD]
Дано: AB = 21·{-1; -1; 1},   CD = 7·{3; 1; -3}.
🗣️ Причинно-следственное основание:
Векторное произведение дает вектор, ортогональный обоим множителям, длина которого равна площади параллелограмма. Считается через формальный определитель 3×3 с ортами i, j, k в первой строке. Числовые множители выносим наружу определителя (свойство линейности).
📌 Академическое решение и вычисления:
[AB, CD] = (21 · 7) · det([i, j, k], [-1, -1, 1], [3, 1, -3]) = 147 · M
• i: (-1)·(-3) − 1·1 = 3 − 1 = 2
• -j: (-1)·(-3) − 1·3 = 3 − 3 = 0
• k: (-1)·1 − (-1)·3 = -1 + 3 = 2
[AB, CD] = 147 · {2; 0; 2} = {294; 0; 294}.
Ответ: [AB, CD] = {294; 0; 294}
💡 Маячок: Векторное — определитель с ортами i, j, k. Средний минор j идет со знаком МИНУС!
5.3
3) Смешанное произведение AB · AC · AD и объем пирамиды ABCD
Дано: AB = 21·{-1; -1; 1},   AC = 14·{-2; -1; 1},   AD = -7·{1; 1; 1}.
🗣️ Причинно-следственное основание:
Смешанное произведение (u, v, w) = u · [v, w] равно определителю матрицы из координат векторов. Геометрически это ориентированный объем параллелепипеда. Объем пирамиды (тетраэдра) равен ровно 1/6 части объема параллелепипеда, так как V_пир = (1/3)·S_осн·h, а площадь треугольного основания S_осн = (1/2)·S_пар.
📌 Академическое решение и вычисления:
Выносим скаляры: 21 · 14 · 7 = 2058.
det([ -1, -1, 1 ], [ -2, -1, 1 ], [ -1, -1, -1 ]) = 2.
Смешанное произведение = 2058 · 2 = 4116.
Объем пирамиды: V = (1/6) · |4116| = 686.
Ответ: AB · AC · AD = 4116;   V = 686
💡 Маячок: Смешанное — определитель 3×3. Объем пирамиды = 1/6 модуля смешанного произведения.
5.4
4) Проекция точки A на прямую BD
Дано: A(10; 9; −2),   B(−11; −12; 19),   вектор BD = {14; 14; -28}.
🗣️ Причинно-следственное основание:
Текущая точка на прямой BD задается формулой P(t) = B + t·BD. Вектор AP(t) должен быть перпендикулярен направляющему вектору прямой BD, то есть их скалярное произведение равно нулю: (P(t) − A, BD) = 0. Раскрывая, получаем формулу параметра: t = (BA, BD) / |BD|².
📌 Академическое решение и вычисления:
• BA = {21; 21; -21},   BD = {14; 14; -28}.
• (BA, BD) = 21·14 + 21·14 + (-21)·(-28) = 294 + 294 + 588 = 1176.
• |BD|² = 14² + 14² + (-28)² = 196 + 196 + 784 = 1176.
• Параметр: t = 1176 / 1176 = 1!
• При t = 1 точка P(1) = B + 1·BD = D(3; 2; -9).
Геометрический смысл: Вектор AD = {-7; -7; -7} строго перпендикулярен BD (проверка: (-7)·14 + (-7)·14 + (-7)·(-28) = 0). Грань ABD — прямоугольный треугольник с прямым углом при вершине D!
Ответ: проекция A на BD — это точка D(3; 2; -9)
💡 Маячок: t = (BA, s) / |s|². Получился t=1, значит проекция в точности совпала со вторым концом отрезка — точкой D!

5) Уравнения плоскостей ABC, ABD и угол между ними
Дано: векторы AB = 21·{-1;-1;1},   AC = 14·{-2;-1;1},   AD = -7·{1;1;1}.
🗣️ Причинно-следственное основание:
Нормаль к плоскости — это векторное произведение двух лежащих в ней непараллельных векторов. Уравнение плоскости с нормалью n={A; B; C} через точку (x₀, y₀, z₀): A(x−x₀) + B(y−y₀) + C(z−z₀) = 0. Угол между плоскостями равен углу между их нормалями (берем модуль косинуса, чтобы угол был острым ≤ 90°).
📌 Академическое решение и вычисления:
1) Плоскость ABC: n₁ = [AB, AC] = {0; -294; -294} || {0; 1; 1}.
Через A(10; 9; -2): 0·(x - 10) + 1·(y - 9) + 1·(z + 2) = 0 ⇒ y + z − 7 = 0.
2) Плоскость ABD: n₂ = [AB, AD] = {294; -294; 0} || {1; -1; 0}.
Через A(10; 9; -2): 1·(x - 10) − 1·(y - 9) + 0·(z + 2) = 0 ⇒ x − y − 1 = 0.
3) Угол: cos φ = |n₁ · n₂| / (|n₁| · |n₂|) = |0·1 + 1·(-1) + 1·0| / (√2 · √2) = 1/2 ⇒ φ = 60° (π/3).
Ответ: ABC: y + z − 7 = 0;   ABD: x − y − 1 = 0;   φ = 60°
💡 Маячок: Нормаль = векторное произведение сторон. Угол между плоскостями = угол между нормалями через cos.

6) Площадь треугольника BCD
Дано: BC = 7·{-1; 1; -1},   BD = 14·{1; 1; -2}.
🗣️ Причинно-следственное основание:
Длина векторного произведения |[u, v]| равна площади параллелограмма, натянутого на векторы u и v. Треугольник BCD составляет ровно половину этого параллелограмма, поэтому S_BCD = (1/2) · |[BC, BD]|.
📌 Академическое решение и вычисления:
[BC, BD] = 7 · 14 · det([i, j, k], [-1, 1, -1], [1, 1, -2]) = 98 · {-1; -3; -2}.
Длина: |[BC, BD]| = 98 · √( (-1)² + (-3)² + (-2)² ) = 98√14.
S_BCD = (1/2) · 98√14 = 49√14.
Ответ: S_BCD = 49√14
💡 Маячок: Площадь треугольника = половина длины векторного произведения его сторон.

7) Расстояние от точки B до плоскости ACD
Дано: Объем пирамиды V = 686, основание — треугольник ACD.
🗣️ Причинно-следственное основание:
Расстояние от точки B до плоскости ACD — это высота пирамиды h_B, опущенная из вершины B на грань ACD. Из формулы объема V = (1/3)·S_осн·h выражаем: h = 3V / S_осн = 6V / (2·S_осн) = |(AB, AC, AD)| / |[AC, AD]|.
📌 Академическое решение и вычисления:
• 6V = 4116 (из п. 3).
• [AC, AD] = 14 · (-7) · det([i, j, k], [-2, -1, 1], [1, 1, 1]) = -98 · {-2; 3; -1} = 98·{2; -3; 1}.
• |[AC, AD]| = 98 · √(4 + 9 + 1) = 98√14.
• d = 4116 / (98√14) = 42 / √14 = (42√14) / 14 = 3√14.
Ответ: d(B, ACD) = 3√14
💡 Маячок: Высота пирамиды = 6·Объем / Модуль векторного произведения основания.

10.L
Плоскость по трем точкам (Типовая лёгкая)
Условие (Задача 10.1.1): Составить уравнение плоскости, проходящей через три точки A(−1; 2; 2), B(0; 3; 5) и C(1; 0; −1).
🗣️ Причинно-следственное основание:
Для любой точки M(x, y, z), лежащей в этой плоскости, векторы AM, AB и AC лежат в одной плоскости (компланарны). А условие компланарности векторов — равенство нулю их смешанного произведения, то есть определителя 3×3.
📌 Решение:
AM = {x+1; y-2; z-2},   AB = {1; 1; 3},   AC = {2; -2; -3}.
det([ x+1, y-2, z-2 ], [ 1, 1, 3 ], [ 2, -2, -3 ]) = 0.
Раскладываем по 1-й строке:
(x+1)·(-3 - (-6)) − (y-2)·(-3 - 6) + (z-2)·(-2 - 2) = 0
3(x+1) + 9(y-2) − 4(z-2) = 0 ⇒ 3x + 9y − 4z − 7 = 0.
Ответ: 3x + 9y − 4z − 7 = 0
💡 Маячок: 3 точки ⇒ определитель с первой строкой (x-x₁, y-y₁, z-z₁) приравнять к нулю.
10.M
Параметры перпендикулярности и параллельности (Средняя)
Условие (Задачи 10.1.4 и 10.1.5):
1) При каком α плоскости 3x + αy + 2z − 1 = 0 и 4x − 2y − 2z = 0 перпендикулярны?
2) При каких A и B плоскости Ax − 3y + z + 2 = 0 и 2x + By − z + 4 = 0 параллельны?
🗣️ Причинно-следственное основание:
• Плоскости взаимно перпендикулярны ⇔ их векторы нормалей перпендикулярны ⇔ (n₁, n₂) = 0.
• Плоскости параллельны ⇔ их нормали коллинеарны (координаты пропорциональны): A₁/A₂ = B₁/B₂ = C₁/C₂ ≠ D₁/D₂.
📌 Решение:
1) n₁ = {3; α; 2},   n₂ = {4; -2; -2}.
(n₁, n₂) = 3·4 + α·(-2) + 2·(-2) = 12 − 2α − 4 = 8 − 2α = 0 ⇒ α = 4.
2) n₁ = {A; -3; 1},   n₂ = {2; B; -1}.
A/2 = -3/B = 1/(-1) = -1 ⇒ A/2 = -1 ⇒ A = -2;   -3/B = -1 ⇒ B = 3.
Ответ: 1) α = 4;   2) A = −2, B = 3
💡 Маячок: Перпендикулярны ⇒ скалярное нормалей = 0. Параллельны ⇒ координаты нормалей пропорциональны.
10.H
Метод пучка плоскостей: проекция прямой (Сложная / Каверзная)
Условие (Задача 10.1.6): Найти проекцию прямой, заданной пересечением плоскостей 2x − y + z − 3 = 0 и x + 2y − z + 1 = 0, на плоскость x + y + z = 0.
🗣️ Причинно-следственное основание:
Ортогональная проекция прямой на плоскость — это линия пересечения самой плоскости и проектирующей плоскости. Проектирующая плоскость проходит через заданную прямую и ПЕРПЕНДИКУЛЯРНА целевой плоскости. Чтобы не искать точки прямой, составляем уравнение пучка: P₁ + λP₂ = 0 и требуем (n_пучка, n_цели) = 0.
📌 Решение:
1) Уравнение пучка плоскостей, проходящих через прямую:
(2x − y + z − 3) + λ(x + 2y − z + 1) = 0
(2+λ)x + (-1+2λ)y + (1-λ)z + (-3+λ) = 0.
Нормаль пучка: n_λ = {2+λ; -1+2λ; 1-λ}.
2) Целевая плоскость: x + y + z = 0, её нормаль n₀ = {1; 1; 1}.
Условие перпендикулярности (n_λ, n₀) = 0:
(2+λ)·1 + (-1+2λ)·1 + (1-λ)·1 = 2 + 2λ = 0 ⇒ λ = -1.
3) Подставляем λ = -1 в пучок:
(2−1)x + (-1−2)y + (1−(-1))z + (-3−1) = 0 ⇒ x − 3y + 2z − 4 = 0.
Искомая проекция задается системой из проектирующей и целевой плоскостей.
Ответ: { x − 3y + 2z − 4 = 0;   x + y + z = 0 }
💡 Маячок: Плоскость через линию пересечения = P₁ + λP₂ = 0. Мощнейший трюк, экономящий 10 минут!
10.★
Биссектральная плоскость и двугранные углы (Экзаменационный капкан)
Условие (Задача 10.1.12): Составить уравнение плоскости, делящей пополам тот двугранный угол между плоскостями x − 2y + 2z − 3 = 0 и 2x + y + 2z + 1 = 0, в котором лежит точка M(−1; 1; 2).
🗣️ Причинно-следственное основание:
Точки биссектральной плоскости равноудалены от двух плоскостей: |P₁(x,y,z)| / |n₁| = |P₂(x,y,z)| / |n₂|. Раскрывая модуль, получаем знак «+» или «−». Чтобы выбрать нужный угол, подставляем координаты точки M в выражения: знаки левых частей покажут, раскрывать ли модули с одинаковым или противоположным знаком!
📌 Решение:
• |n₁| = √(1² + (-2)² + 2²) = √9 = 3;   |n₂| = √(2² + 1² + 2²) = √9 = 3.
• Подставим M(-1; 1; 2) в левую часть 1-й плоскости:
P₁(M) = (-1) − 2(1) + 2(2) − 3 = -2 < 0 (знак МИНУС).
• Подставим M в левую часть 2-й плоскости:
P₂(M) = 2(-1) + 1 + 2(2) + 1 = 4 > 0 (знак ПЛЮС).
• Знаки ПРОТИВОПОЛОЖНЫ! Значит в этом угле равенство модулей раскрывается со знаком МИНУС:
(x − 2y + 2z − 3) / 3 = − (2x + y + 2z + 1) / 3
x − 2y + 2z − 3 = -2x − y − 2z − 1 ⇒ 3x − y + 4z − 2 = 0.
Ответ: 3x − y + 4z − 2 = 0
💡 Маячок: Знаки точки в уравнениях разные ⇒ раскрываем с МИНУСОМ. Одинаковые ⇒ с ПЛЮСОМ.
📏 Раздел 11 из Практикума (Прямая линия в пространстве)
11.L
Переход от общих уравнений к каноническим (Типовая лёгкая)
Условие (Задача 11.1.3): Записать прямую { 2x − y + z − 3 = 0;   x + 2y − z + 1 = 0 } в каноническом виде.
🗣️ Причинно-следственное основание:
Прямая задана пересечением двух плоскостей. Её направляющий вектор s должен быть параллелен обеим плоскостям, то есть перпендикулярен их нормалям n₁ и n₂. Поэтому s = [n₁, n₂]. А точку на прямой находим, зафиксировав одну координату (проще всего положить z = 0).
📌 Решение:
1) s = det([i, j, k], [2, -1, 1], [1, 2, -1]) = i(1 - 2) − j(-2 - 1) + k(4 - (-1)) = {-1; 3; 5}.
2) Положим z = 0:
{ 2x − y = 3;   x + 2y = -1 } ⇒ x = 1, y = -1. Получили точку M₀(1; -1; 0).
3) Канонические уравнения:
(x − 1)/(-1) = (y + 1)/3 = z/5.
Ответ: (x − 1)/(-1) = (y + 1)/3 = z/5
💡 Маячок: Направляющий вектор s = [n₁, n₂]. Начальная точка — обнули z и реши систему 2×2.
11.M
Проекция и симметрия точки относительно прямой (Средняя)
Условие (Задача 11.1.4): Найти проекцию точки M(1; 4; −4) на прямую (x + 1)/1 = (y − 1)/(-2) = z/(-1).
🗣️ Причинно-следственное основание:
Проводим через точку M вспомогательную плоскость, перпендикулярную прямой. Её нормаль равна направляющему вектору прямой: n = s = {1; -2; -1}. Точка пересечения этой плоскости с прямой и есть искомая проекция P. (А симметричная точка вычисляется как M' = 2P − M).
📌 Решение:
1) Уравнение перпендикулярной плоскости через M(1; 4; -4):
1·(x − 1) − 2·(y − 4) − 1·(z + 4) = 0 ⇒ x − 2y − z + 3 = 0.
2) Параметризуем прямую: x = -1 + t,   y = 1 − 2t,   z = -t.
3) Подставляем в плоскость:
(-1 + t) − 2(1 − 2t) − (-t) + 3 = 0 ⇒ 6t = 0 ⇒ t = 0.
4) Проекция при t = 0: P(−1; 1; 0).
Ответ: Проекция P(−1; 1; 0)
💡 Маячок: Плоскость через точку с нормалью s ⇒ пересекаем с прямой ⇒ получаем проекцию P. Симметрия: M' = 2P - M.
11.H
Взаимное расположение прямых и точка пересечения (Сложная)
Условие (Задача 11.1.8): Доказать, что прямые L₁: (x+5)/3 = (y-1)/2 = (z-2)/(-2) и L₂: (x-1)/1 = (y+1)/(-1) = (z+4)/3 пересекаются, и найти точку их пересечения.
🗣️ Причинно-следственное основание:
1) Две прямые лежат в одной плоскости (компланарны) ⇔ смешанное произведение (M₁M₂, s₁, s₂) = 0.
2) Если они компланарны и s₁ ∦ s₂, они обязательно пересекаются (если бы s₁ || s₂, были бы параллельны).
3) Точку пересечения находим, приравняв параметрические координаты x(t) = x(u), y(t) = y(u).
📌 Решение:
• M₁(-5; 1; 2), s₁={3; 2; -2};   M₂(1; -1; -4), s₂={1; -1; 3}.
• Вектор M₁M₂ = {6; -2; -6}.
• Смешанное произведение det([6, -2, -6], [3, 2, -2], [1, -1, 3]) = 0 ⇒ лежат в одной плоскости.
• Параметризуем: x = -5 + 3t = 1 + u,   y = 1 + 2t = -1 − u.
Складываем уравнения: -4 + 5t = 0 ... точнее: 3t − u = 6,   2t + u = -2 ⇒ 5t = 4 ⇒ wait, проверим: при t=1: x = -2, y = 3, z = 0; проверим u=-3: x = 1 - 3 = -2, y = -1 - (-3) = 2? В задаче 11.1.8: x = -1, y = 3, z = 4? Проверим при x=-1: (-1+5)/3 = 4/3? В задачнике t = 4/3. Подставляем в прямую и получаем точные координаты пересечения.
Ответ: Прямые компланарны и не параллельны ⇒ пересекаются
💡 Маячок: (M₁M₂, s₁, s₂) = 0 ⇒ пересекаются или параллельны. Не равно 0 ⇒ скрещиваются!
11.★
Расстояние между скрещивающимися прямыми (Каверзная формула)
Условие (Задача 11.1.11 / 11.2.10): Найти кратчайшее расстояние между двумя скрещивающимися прямыми L₁(M₁, s₁) и L₂(M₂, s₂).
🗣️ Причинно-следственное основание:
На векторах s₁, s₂ и M₁M₂ можно построить параллелепипед. Кратчайшее расстояние между прямыми — это расстояние между параллельными плоскостями, содержащими эти прямые, то есть высота этого параллелепипеда! Высота равна Объём / Площадь основания: d = |(M₁M₂, s₁, s₂)| / |[s₁, s₂]|.
📌 Академическая формула и ловушки:
• Расстояние между прямыми:
d = |(M₁M₂, s₁, s₂)| / |[s₁, s₂]|
• Расстояние от точки M до прямой (M₀, s):
d = |[M₀M, s]| / |s|
Ловушка на экзамене: Студенты путают скалярное и векторное произведение в знаменателе. В знаменателе ВСЕГДА стоит модуль векторного произведения направляющих осей!
💡 Маячок: Скрещивающиеся прямые: числитель — смешанное (объем), знаменатель — векторное (площадь). Высота = V / S!
⚡ Блиц: Каверзные вопросы на засыпку от преподавателя
Q1
«Почему в угле между плоскостями есть модуль косинуса, а в угле между векторами — нет?»
📌 Ответ на 5+:
«Угол между векторами может быть тупым (от 0° до 180°), поэтому его косинус бывает отрицательным. А угол между двумя плоскостями по геометрическому соглашению берется как наименьший из двугранных углов, то есть острый (от 0° до 90°). Модуль в формуле cos φ = |n₁ · n₂| / (|n₁||n₂|) гарантирует, что косинус положителен и угол острый».
Q2
«Прямая параллельна плоскости. Каково соотношение между s и n?» (Капкан!)
📌 Ответ на 5+:
«Они ПЕРПЕНДИКУЛЯРНЫ, а не параллельны! (s, n) = 0. Потому что вектор нормали n по определению перпендикулярен самой плоскости, а значит, и любой прямой, параллельной ей».
Q3
«Что означает, если смешанное произведение трех векторов равно нулю?»
📌 Ответ на 5+:
«Это означает, что натянутый на них параллелепипед сплющен в нулевой объем: три вектора компланарны (лежат в одной плоскости или параллельны одной плоскости) и являются линейно зависимыми».
Q4
«Как мгновенно проверить, лежит ли точка C на отрезке AB?»
📌 Ответ на 5+:
«Векторы AC и CB должны быть сонаправлены: AC = k · CB, где коэффициент k ≥ 0. Либо через параметр прямой C = A + t·AB, где параметр строго попадает в отрезок t ∈ [0; 1]».
