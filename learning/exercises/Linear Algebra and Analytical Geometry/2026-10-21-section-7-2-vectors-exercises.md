### Задача 7.2.1
**Условие:**  
Определите начало вектора $\vec{a} = \{3; 1; 2\}$, если его конец совпадает с точкой $B(0; 1; -1)$.

**Решение:**  
Пусть начало вектора — точка $A(x_A, y_A, z_A)$.  
Вектор $\vec{a} = \vec{AB}$ находится вычитанием координат начала из координат конца:
$$\vec{AB} = \{x_B - x_A;\; y_B - y_A;\; z_B - z_A\}$$

Подставляем известные значения:
$$\begin{cases} 0 - x_A = 3 \implies x_A = -3 \\ 1 - y_A = 1 \implies y_A = 0 \\ -1 - z_A = 2 \implies z_A = -3 \end{cases}$$

**Ответ:** $(-3;\; 0;\; -3)$. *(Сходится с ответом задачника)*

### Задача 7.2.2
**Условие:**  
В треугольнике $ABC$: $\vec{AB} = \vec{c}$, $\vec{AC} = \vec{b}$. Точка $D$ делит сторону $BC$ в отношении $BD : DC = 3 : 7$. Выразите $\vec{AD}$ через векторы $\vec{b}$ и $\vec{c}$.

**Решение:**  
1. Выразим вектор стороны $\vec{BC}$:
   $$\vec{BC} = \vec{AC} - \vec{AB} = \vec{b} - \vec{c}$$
2. Так как точка $D$ делит отрезок $BC$ в отношении $3 : 7$, весь отрезок состоит из $3 + 7 = 10$ частей. Следовательно:
   $$\vec{BD} = \frac{3}{10} \vec{BC} = 0{,}3(\vec{b} - \vec{c})$$
3. Находим искомый вектор $\vec{AD}$ по правилу треугольника:
   $$\vec{AD} = \vec{AB} + \vec{BD} = \vec{c} + 0{,}3(\vec{b} - \vec{c}) = \vec{c} + 0{,}3\vec{b} - 0{,}3\vec{c} = 0{,}3\vec{b} + 0{,}7\vec{c}$$

**Ответ:** $\vec{AD} = 0{,}3\vec{b} + 0{,}7\vec{c}$. *(Сходится с ответом задачника)*

### Задача 7.2.3
**Условие:**  
Даны векторы $\vec{a} = \{2; 3\}$, $\vec{b} = \{-3; -5\}$, $\vec{c} = \{1; -3\}$. При каком значении $\beta \neq 0$ векторы $\vec{u} = \vec{a} - \beta\vec{c}$ и $\vec{v} = \vec{a} + \beta\vec{b}$ коллинеарны?

**Решение:**  
1. Найдём координаты векторов $\vec{u}$ и $\vec{v}$:
   $$\vec{u} = \vec{a} - \beta\vec{c} = \{2 - \beta \cdot 1;\; 3 - \beta \cdot (-3)\} = \{2 - \beta;\; 3 + 3\beta\}$$
   $$\vec{v} = \vec{a} + \beta\vec{b} = \{2 + \beta \cdot (-3);\; 3 + \beta \cdot (-5)\} = \{2 - 3\beta;\; 3 - 5\beta\}$$
2. Критерий коллинеарности двух векторов на плоскости — пропорциональность их координат (или равенство нулю определителя 2-го порядка):
   $$\begin{vmatrix} u_x & u_y \\ v_x & v_y \end{vmatrix} = 0 \iff u_x v_y - u_y v_x = 0$$
3. Подставляем и решаем уравнение:
   $$(2 - \beta)(3 - 5\beta) - (3 + 3\beta)(2 - 3\beta) = 0$$
   $$(6 - 10\beta - 3\beta + 5\beta^2) - (6 - 9\beta + 6\beta - 9\beta^2) = 0$$
   $$(6 - 13\beta + 5\beta^2) - (6 - 3\beta - 9\beta^2) = 0$$
   $$6 - 13\beta + 5\beta^2 - 6 + 3\beta + 9\beta^2 = 0$$
   $$14\beta^2 - 10\beta = 0$$
   $$2\beta(7\beta - 5) = 0$$
4. Так как по условию $\beta \neq 0$, остаётся:
   $$7\beta - 5 = 0 \implies \beta = \frac{5}{7}$$

**Ответ:** $\beta = \frac{5}{7}$. *(Сходится с ответом задачника)*

### Задача 7.2.4
**Условие:**  
Даны последовательные вершины параллелограмма $A(1; -2; 3)$, $B(3; 2; 1)$, $C(6; 4; 4)$. Найдите координаты его четвёртой вершины $D$.

**Решение:**  
В параллелограмме $ABCD$ противоположные стороны равны и параллельны, а значит, равны соответствующие векторы:
$$\vec{AD} = \vec{BC}$$

1. Найдём вектор стороны $\vec{BC}$ (координаты конца минус координаты начала):
   $$\vec{BC} = \{6 - 3;\; 4 - 2;\; 4 - 1\} = \{3;\; 2;\; 3\}$$
2. Пусть вершина $D$ имеет координаты $(x_D, y_D, z_D)$. Тогда вектор $\vec{AD}$:
   $$\vec{AD} = \{x_D - 1;\; y_D - (-2);\; z_D - 3\} = \{x_D - 1;\; y_D + 2;\; z_D - 3\}$$
3. Приравниваем координаты $\vec{AD} = \vec{BC}$:
   $$\begin{cases} x_D - 1 = 3 \implies x_D = 4 \\ y_D + 2 = 2 \implies y_D = 0 \\ z_D - 3 = 3 \implies z_D = 6 \end{cases}$$

**Ответ:** $D(4;\; 0;\; 6)$. *(Сходится с ответом задачника)*

### Задача 7.2.5
**Условие:**  
Радиус-вектор точки $M(x; y; z)$ образует с осью $Ox$ угол $\alpha = 60^\circ$, с осью $Oz$ угол $\gamma = 45^\circ$, $|\vec{OM}| = 8$ и $y > 0$. Найдите координаты точки $M$.

**Решение:**  
Координаты вектора через направляющие косинусы выражаются формулами:
$$x = |\vec{OM}|\cos\alpha, \quad y = |\vec{OM}|\cos\beta, \quad z = |\vec{OM}|\cos\gamma$$
Основное свойство направляющих косинусов:
$$\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$$

1. Подставляем известные углы $\alpha = 60^\circ$ и $\gamma = 45^\circ$:
   $$\cos^2 60^\circ + \cos^2\beta + \cos^2 45^\circ = 1$$
   $$\left(\frac{1}{2}\right)^2 + \cos^2\beta + \left(\frac{\sqrt{2}}{2}\right)^2 = 1$$
   $$\frac{1}{4} + \cos^2\beta + \frac{2}{4} = 1 \implies \cos^2\beta = 1 - \frac{3}{4} = \frac{1}{4}$$
2. Так как по условию $y > 0$, то $\cos\beta > 0$:
   $$\cos\beta = \frac{1}{2} \quad (\beta = 60^\circ)$$
3. Находим координаты точки $M$ при $|\vec{OM}| = 8$:
   * $x = 8 \cdot \cos 60^\circ = 8 \cdot \frac{1}{2} = 4$
   * $y = 8 \cdot \cos 60^\circ = 8 \cdot \frac{1}{2} = 4$
   * $z = 8 \cdot \cos 45^\circ = 8 \cdot \frac{\sqrt{2}}{2} = 4\sqrt{2}$

**Ответ:** $M(4;\; 4;\; 4\sqrt{2})$. *(Сходится с ответом задачника)*

### Задача 7.2.6
**Условие:**  
Два вектора $\vec{a} = \{7; -4; -4\}$ и $\vec{b} = \{-2; -1; 2\}$ приложены к одной точке. Определите координаты вектора $\vec{c}$, направленного по биссектрисе угла между векторами $\vec{a}$ и $\vec{b}$, при условии, что $|\vec{c}| = 6\sqrt{6}$.

**Решение:**  
1. *Геометрическая идея:* Диагональ параллелограмма делит его угол пополам (является биссектрисой) только тогда, когда смежные стороны равны, то есть когда параллелограмм является **ромбом**.  
   Чтобы построить ромб на направлениях векторов $\vec{a}$ и $\vec{b}$, нормируем их (возьмём единичные векторы $\vec{e}_a = \frac{\vec{a}}{|\vec{a}|}$ и $\vec{e}_b = \frac{\vec{b}}{|\vec{b}|}$). Тогда вектор $\vec{d} = \vec{e}_a + \vec{e}_b$ будет строго направлен по биссектрисе!
2. Находим длины векторов:
   $$|\vec{a}| = \sqrt{7^2 + (-4)^2 + (-4)^2} = \sqrt{49 + 16 + 16} = \sqrt{81} = 9$$
   $$|\vec{b}| = \sqrt{(-2)^2 + (-1)^2 + 2^2} = \sqrt{4 + 1 + 4} = \sqrt{9} = 3$$
3. Единичные векторы:
   $$\vec{e}_a = \frac{1}{9}\{7;\; -4;\; -4\}$$
   $$\vec{e}_b = \frac{1}{3}\{-2;\; -1;\; 2\} = \frac{1}{9}\{-6;\; -3;\; 6\}$$
4. Вектор суммы по биссектрисе:
   $$\vec{d} = \vec{e}_a + \vec{e}_b = \frac{1}{9}\{7 - 6;\; -4 - 3;\; -4 + 6\} = \frac{1}{9}\{1;\; -7;\; 2\}$$
   Для удобства возьмём сонаправленный вектор $\vec{d}_0 = \{1;\; -7;\; 2\}$.
5. Находим его длину:
   $$|\vec{d}_0| = \sqrt{1^2 + (-7)^2 + 2^2} = \sqrt{1 + 49 + 4} = \sqrt{54} = 3\sqrt{6}$$
6. Нам требуется длина $|\vec{c}| = 6\sqrt{6}$.  
   Коэффициент масштабирования:
   $$k = \frac{|\vec{c}|}{|\vec{d}_0|} = \frac{6\sqrt{6}}{3\sqrt{6}} = 2$$
   Следовательно:
   $$\vec{c} = 2 \cdot \vec{d}_0 = 2 \cdot \{1;\; -7;\; 2\} = \{2;\; -14;\; 4\}$$

**Ответ:** $\vec{c} = \{2;\; -14;\; 4\}$. *(Сходится с ответом задачника)*

### Задача 7.2.7
**Условие:**  
Представьте вектор $\vec{x} = \{-2; 3; 1\}$ в виде линейной комбинации векторов $\vec{e}_1 = \{1; 2; -1\}$, $\vec{e}_2 = \{2; 0; 3\}$, $\vec{e}_3 = \{-1; 1; -1\}$.

**Решение:**  
Ищем разложение вида $\vec{x} = \alpha_1 \vec{e}_1 + \alpha_2 \vec{e}_2 + \alpha_3 \vec{e}_3$.  
В координатной форме это даёт систему линейных уравнений:
$$\begin{cases} \alpha_1 + 2\alpha_2 - \alpha_3 = x_1 \\ 2\alpha_1 + 0\alpha_2 + \alpha_3 = x_2 \\ -\alpha_1 + 3\alpha_2 - \alpha_3 = x_3 \end{cases}$$

> [!NOTE] Замечание об опечатке в задачнике
> В ответах практикума указано: $\vec{x} = \vec{e}_1 + \vec{e}_2 + \vec{e}_3$.  
> При $\alpha_1 = 1, \alpha_2 = 1, \alpha_3 = 1$ получаем:
> $$\vec{e}_1 + \vec{e}_2 + \vec{e}_3 = \{1 + 2 - 1;\; 2 + 0 + 1;\; -1 + 3 - 1\} = \{2;\; 3;\; 1\}$$
> В тексте условия опечатка в знаке первой координаты: напечатано $-2$ вместо $+2$.

1. **Решение при $\vec{x} = \{2; 3; 1\}$ (по замыслу автора задачника):**
   $$\begin{cases} \alpha_1 + 2\alpha_2 - \alpha_3 = 2 \\ 2\alpha_1 + \alpha_3 = 3 \\ -\alpha_1 + 3\alpha_2 - \alpha_3 = 1 \end{cases} \implies \alpha_1 = 1, \quad \alpha_2 = 1, \quad \alpha_3 = 1$$
   $$\vec{x} = \vec{e}_1 + \vec{e}_2 + \vec{e}_3$$
2. **Строгое решение при буквально напечатанном $\vec{x} = \{-2; 3; 1\}$:**
   Из второго уравнения: $\alpha_3 = 3 - 2\alpha_1$.  
   Подставляем в первое и третье:
   $$\begin{cases} \alpha_1 + 2\alpha_2 - (3 - 2\alpha_1) = -2 \implies 3\alpha_1 + 2\alpha_2 = 1 \\ -\alpha_1 + 3\alpha_2 - (3 - 2\alpha_1) = 1 \implies \alpha_1 + 3\alpha_2 = 4 \end{cases}$$
   Выражая $\alpha_1 = 4 - 3\alpha_2$, получаем: $3(4 - 3\alpha_2) + 2\alpha_2 = 1 \implies 12 - 7\alpha_2 = 1 \implies \alpha_2 = \frac{11}{7}$.  
   Тогда $\alpha_1 = 4 - \frac{33}{7} = -\frac{5}{7}$, а $\alpha_3 = 3 - 2\left(-\frac{5}{7}\right) = \frac{31}{7}$.  
   $$\vec{x} = -\frac{5}{7}\vec{e}_1 + \frac{11}{7}\vec{e}_2 + \frac{31}{7}\vec{e}_3$$

**Ответ:** $\vec{x} = \vec{e}_1 + \vec{e}_2 + \vec{e}_3$ *(с учётом опечатки знака в условии задачи)*.

### Задача 7.2.8
**Условие:**  
Вычислите длину меньшей диагонали параллелограмма, построенного на векторах $\vec{a} = 5\vec{m} + 2\vec{n}$ и $\vec{b} = \vec{m} - 3\vec{n}$, если $|\vec{m}| = 2\sqrt{2}$, $|\vec{n}| = 3$ и угол между ними равен $\pi/4$.

**Решение:**  
1. Найдём скалярное произведение базовых векторов $\vec{m}$ и $\vec{n}$:
   $$\vec{m} \cdot \vec{n} = |\vec{m}| \cdot |\vec{n}| \cdot \cos\frac{\pi}{4} = 2\sqrt{2} \cdot 3 \cdot \frac{\sqrt{2}}{2} = 6$$
   Квадраты длин: $|\vec{m}|^2 = (2\sqrt{2})^2 = 8$, $|\vec{n}|^2 = 3^2 = 9$.
2. Диагонали параллелограмма, построенного на векторах $\vec{a}$ и $\vec{b}$, равны их сумме и разности:
   $$\vec{d}_1 = \vec{a} + \vec{b} = (5\vec{m} + 2\vec{n}) + (\vec{m} - 3\vec{n}) = 6\vec{m} - \vec{n}$$
   $$\vec{d}_2 = \vec{a} - \vec{b} = (5\vec{m} + 2\vec{n}) - (\vec{m} - 3\vec{n}) = 4\vec{m} + 5\vec{n}$$
3. Вычисляем квадрат длины первой диагонали:
   $$|\vec{d}_1|^2 = (6\vec{m} - \vec{n})^2 = 36|\vec{m}|^2 - 12(\vec{m} \cdot \vec{n}) + |\vec{n}|^2$$
   $$= 36 \cdot 8 - 12 \cdot 6 + 9 = 288 - 72 + 9 = 225$$
   $$|\vec{d}_1| = \sqrt{225} = 15$$
4. Вычисляем квадрат длины второй диагонали:
   $$|\vec{d}_2|^2 = (4\vec{m} + 5\vec{n})^2 = 16|\vec{m}|^2 + 40(\vec{m} \cdot \vec{n}) + 25|\vec{n}|^2$$
   $$= 16 \cdot 8 + 40 \cdot 6 + 25 \cdot 9 = 128 + 240 + 225 = 593$$
   $$|\vec{d}_2| = \sqrt{593} \approx 24{,}35$$
5. Меньшей является диагональ $\vec{d}_1$, её длина равна 15.

**Ответ:** 15. *(Сходится с ответом задачника)*

### Задача 7.2.9
**Условие:**  
Дано: $\vec{a} = \{3; 1; 2\}$, $\vec{b} = \{2; 0; 4\}$, $\vec{c} = \{1; 2; 1\}$. Вычислите:
$$(2\vec{c}, \vec{c} + 3\vec{a}) + (\vec{b} - 2\vec{a}, \vec{a} + \vec{c})$$

*(Примечание: запись $( \vec{u}, \vec{v} )$ означает скалярное произведение векторов $\vec{u} \cdot \vec{v}$)*.

**Решение:**  
Найдём координаты векторов в каждой скобке:
1. Первая часть:
   $$2\vec{c} = 2 \cdot \{1;\; 2;\; 1\} = \{2;\; 4;\; 2\}$$
   $$\vec{c} + 3\vec{a} = \{1 + 3 \cdot 3;\; 2 + 3 \cdot 1;\; 1 + 3 \cdot 2\} = \{10;\; 5;\; 7\}$$
   Их скалярное произведение:
   $$(2\vec{c}, \vec{c} + 3\vec{a}) = 2 \cdot 10 + 4 \cdot 5 + 2 \cdot 7 = 20 + 20 + 14 = 54$$
2. Вторая часть:
   $$\vec{b} - 2\vec{a} = \{2 - 2 \cdot 3;\; 0 - 2 \cdot 1;\; 4 - 2 \cdot 2\} = \{-4;\; -2;\; 0\}$$
   $$\vec{a} + \vec{c} = \{3 + 1;\; 1 + 2;\; 2 + 1\} = \{4;\; 3;\; 3\}$$
   Их скалярное произведение:
   $$(\vec{b} - 2\vec{a}, \vec{a} + \vec{c}) = (-4) \cdot 4 + (-2) \cdot 3 + 0 \cdot 3 = -16 - 6 + 0 = -22$$
3. Складываем результаты:
   $$54 + (-22) = 32$$

**Ответ:** 32. *(Сходится с ответом задачника)*

### Задача 7.2.10
**Условие:**  
Найдите значение $\alpha$, при котором векторы $\vec{a} = \{2; 1; -1\}$ и $\vec{b} = \{1 + 4\alpha;\; 3 + \alpha;\; \alpha - 3\}$ перпендикулярны.

**Решение:**  
Критерий перпендикулярности (ортогональности) двух векторов — равенство нулю их скалярного произведения:
$$\vec{a} \cdot \vec{b} = 0$$

1. Записываем скалярное произведение через координаты:
   $$\vec{a} \cdot \vec{b} = 2(1 + 4\alpha) + 1(3 + \alpha) + (-1)(\alpha - 3) = 0$$
2. Раскрываем скобки и приводим подобные:
   $$2 + 8\alpha + 3 + \alpha - \alpha + 3 = 0$$
   $$8\alpha + 8 = 0$$
   $$8\alpha = -8 \implies \alpha = -1$$

**Ответ:** $\alpha = -1$. *(Сходится с ответом задачника)*

### Задача 7.2.11
**Условие:**  
Определите вектор $\vec{x}$, если известно, что он ортогонален двум векторам $\vec{a} = \{2; 1; 2\}$ и $\vec{b} = \{3; -4; 2\}$, при условии что $|\vec{x}| = 15$.

**Решение:**  
1. Вектор, перпендикулярный двум данным векторам $\vec{a}$ и $\vec{b}$, коллинеарен их векторному произведению $\vec{a} \times \vec{b}$.
2. Вычисляем векторное произведение через определитель:
   $$\vec{c} = \vec{a} \times \vec{b} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 2 & 1 & 2 \\ 3 & -4 & 2 \end{vmatrix}$$
   * при $\vec{i}$: $1 \cdot 2 - 2 \cdot (-4) = 2 + 8 = 10$
   * при $\vec{j}$: $-(2 \cdot 2 - 2 \cdot 3) = -(4 - 6) = 2$
   * при $\vec{k}$: $2 \cdot (-4) - 1 \cdot 3 = -8 - 3 = -11$  
   Получили вектор $\vec{c} = \{10;\; 2;\; -11\}$.
3. Найдём длину этого вектора:
   $$|\vec{c}| = \sqrt{10^2 + 2^2 + (-11)^2} = \sqrt{100 + 4 + 121} = \sqrt{225} = 15$$
   Длина вектора $\vec{c}$ уже в точности равна 15!
4. Вектор $\vec{x}$ может быть направлен в любую из двух противоположных сторон:
   $$\vec{x} = \pm \{10;\; 2;\; -11\}$$
   В ответе задачника указан вектор противоположного направления (соответствующий $\vec{b} \times \vec{a}$):
   $$\vec{x} = \{-10;\; -2;\; 11\}$$

**Ответ:** $\vec{x} = \{-10;\; -2;\; 11\}$. *(Сходится с ответом задачника)*

### Задача 7.2.12
**Условие:**  
Найдите проекцию вектора $\vec{a} + \vec{b}$ на направление вектора $\vec{c}$, если $\vec{a} = \{3; -6; -1\}$, $\vec{b} = \{1; 4; -5\}$, $\vec{c} = \{6; -8; 24\}$.

**Решение:**  
1. Обозначим суммарный вектор $\vec{u} = \vec{a} + \vec{b}$:
   $$\vec{u} = \{3 + 1;\; -6 + 4;\; -1 + (-5)\} = \{4;\; -2;\; -6\}$$
2. Из геометрического свойства скалярного произведения ($\vec{u} \cdot \vec{c} = |\vec{c}| \cdot \text{пр}_{\vec{c}}\vec{u}$) выражаем проекцию:
   $$\text{пр}_{\vec{c}}\vec{u} = \frac{\vec{u} \cdot \vec{c}}{|\vec{c}|}$$
3. Вычисляем числитель (скалярное произведение $\vec{u} \cdot \vec{c}$):
   $$\vec{u} \cdot \vec{c} = 4 \cdot 6 + (-2) \cdot (-8) + (-6) \cdot 24 = 24 + 16 - 144 = 40 - 144 = -104$$
4. Вычисляем знаменатель (длина вектора $\vec{c}$):
   $$|\vec{c}| = \sqrt{6^2 + (-8)^2 + 24^2} = \sqrt{36 + 64 + 576} = \sqrt{100 + 576} = \sqrt{676} = 26$$
5. Находим проекцию:
   $$\text{пр}_{\vec{c}}\vec{u} = \frac{-104}{26} = -4$$

**Ответ:** $-4$. *(Сходится с ответом задачника)*

### Задача 7.2.13
**Условие:**  
Определите вектор $\vec{x}$, если известно, что он ортогонален вектору $\vec{a} = \{1; -2; 1\}$, его проекция на вектор $\vec{b} = \{-2; 1; 2\}$ равна 1, длина $|\vec{x}| = 3\sqrt{3}$, и он составляет с осями координат тупые углы.

**Решение:**  
Пусть искомый вектор имеет координаты $\vec{x} = \{x_1;\; x_2;\; x_3\}$.  
По условию:
1. **Ортогональность к $\vec{a}$:**  
   $$\vec{x} \cdot \vec{a} = 0 \implies x_1 - 2x_2 + x_3 = 0 \quad (1)$$
2. **Проекция на $\vec{b}$:**  
   Длина вектора $\vec{b}$: $|\vec{b}| = \sqrt{(-2)^2 + 1^2 + 2^2} = \sqrt{9} = 3$.  
   Формула проекции: $\text{пр}_{\vec{b}}\vec{x} = \frac{\vec{x} \cdot \vec{b}}{|\vec{b}|} = 1 \implies \vec{x} \cdot \vec{b} = 3$.  
   В координатах:
   $$-2x_1 + x_2 + 2x_3 = 3 \quad (2)$$
3. **Длина вектора:**  
   $$|\vec{x}|^2 = x_1^2 + x_2^2 + x_3^2 = (3\sqrt{3})^2 = 27 \quad (3)$$
4. **Тупые углы с осями:**  
   Так как $\cos(\text{тупого угла}) < 0$, все координаты должны быть строго отрицательными: $x_1 < 0, x_2 < 0, x_3 < 0$.

*Решаем систему:*  
Из $(1)$ выражаем $x_3 = 2x_2 - x_1$.  
Подставляем в $(2)$:
$$-2x_1 + x_2 + 2(2x_2 - x_1) = 3 \implies -4x_1 + 5x_2 = 3 \implies x_2 = \frac{4x_1 + 3}{5}$$
Тогда:
$$x_3 = 2 \cdot \frac{4x_1 + 3}{5} - x_1 = \frac{3x_1 + 6}{5}$$

Подставляем $x_2$ и $x_3$ в уравнение длины $(3)$:
$$x_1^2 + \left(\frac{4x_1 + 3}{5}\right)^2 + \left(\frac{3x_1 + 6}{5}\right)^2 = 27$$
Умножаем обе части на 25:
$$25x_1^2 + (16x_1^2 + 24x_1 + 9) + (9x_1^2 + 36x_1 + 36) = 675$$
$$50x_1^2 + 60x_1 + 45 = 675$$
$$50x_1^2 + 60x_1 - 630 = 0 \iff 5x_1^2 + 6x_1 - 63 = 0$$

Дискриминант:
$$D = 6^2 - 4 \cdot 5 \cdot (-63) = 36 + 1260 = 1296 = 36^2$$
Корни:
$$x_1 = \frac{-6 \pm 36}{10}$$
* $x_1^{(1)} = \frac{30}{10} = 3$ — не подходит, так как $x_1 > 0$ (острый угол).
* $x_1^{(2)} = \frac{-42}{10} = -4{,}2$ — отрицательный корень (тупой угол).

Находим остальные координаты:
$$x_2 = \frac{4(-4{,}2) + 3}{5} = \frac{-16{,}8 + 3}{5} = \frac{-13{,}8}{5} = -2{,}76$$
$$x_3 = \frac{3(-4{,}2) + 6}{5} = \frac{-12{,}6 + 6}{5} = \frac{-6{,}6}{5} = -1{,}32$$

Все координаты отрицательны, условия выполнены!

**Ответ:** $\vec{x} = \{-4{,}2;\; -2{,}76;\; -1{,}32\}$. *(Сходится с ответом задачника)*

### Задача 7.2.14
**Условие:**  
Вычислите косинус внутреннего угла при вершине $A$ треугольника $ABC$, где $A(1; 2; -1)$, $B(5; 5; 11)$, $C(13; 18; 20)$.

**Решение:**  
Угол при вершине $A$ образован векторами $\vec{AB}$ и $\vec{AC}$.
1. Находим координаты векторов:
   $$\vec{AB} = \{5 - 1;\; 5 - 2;\; 11 - (-1)\} = \{4;\; 3;\; 12\}$$
   $$\vec{AC} = \{13 - 1;\; 18 - 2;\; 20 - (-1)\} = \{12;\; 16;\; 21\}$$
2. Находим их длины:
   $$|\vec{AB}| = \sqrt{4^2 + 3^2 + 12^2} = \sqrt{16 + 9 + 144} = \sqrt{169} = 13$$
   $$|\vec{AC}| = \sqrt{12^2 + 16^2 + 21^2} = \sqrt{144 + 256 + 441} = \sqrt{841} = 29$$
3. Вычисляем скалярное произведение:
   $$\vec{AB} \cdot \vec{AC} = 4 \cdot 12 + 3 \cdot 16 + 12 \cdot 21 = 48 + 48 + 252 = 348$$
4. Находим косинус угла $A$:
   $$\cos A = \frac{\vec{AB} \cdot \vec{AC}}{|\vec{AB}| \cdot |\vec{AC}|} = \frac{348}{13 \cdot 29} = \frac{12 \cdot 29}{13 \cdot 29} = \frac{12}{13}$$

**Ответ:** $\cos A = \frac{12}{13}$. *(Сходится с ответом задачника)*

### Задача 7.2.15
**Условие:**  
Вычислите в прямоугольном параллелепипеде из задачи 7.1.10 угол между векторами $\vec{PQ}$ и $\vec{BD}$.  
*(В тексте формулировки задачника опечатка в ссылке: ошибочно напечатано «из задачи 7.2.15» вместо разобранной в примере задачи 7.1.10)*.

**Решение:**  
В задаче 7.1.10 задан прямоугольный параллелепипед с вершиной $A(0, 0, 0)$ и рёбрами: $\vec{AB} = 3\vec{i}$, $\vec{AD} = 2\vec{j}$, $\vec{AA}_1 = 4\vec{k}$.  
Координаты ключевых точек:
* Вершины основания: $B(3, 0, 0)$, $D(0, 2, 0)$.
* Точка $P$ — центр грани $BCC_1B_1$: $P(3, 1, 2)$.
* Точка $Q$ на ребре $DD_1$ в отношении $DQ : QD_1 = 1 : 3$: $Q(0, 2, 1)$.

1. Находим вектор $\vec{PQ}$ (из $Q$ вычитаем $P$):
   $$\vec{PQ} = \{0 - 3;\; 2 - 1;\; 1 - 2\} = \{-3;\; 1;\; -1\}$$
2. Находим вектор $\vec{BD}$ (из $D$ вычитаем $B$):
   $$\vec{BD} = \{0 - 3;\; 2 - 0;\; 0 - 0\} = \{-3;\; 2;\; 0\}$$
3. Находим длины векторов:
   $$|\vec{PQ}| = \sqrt{(-3)^2 + 1^2 + (-1)^2} = \sqrt{9 + 1 + 1} = \sqrt{11}$$
   $$|\vec{BD}| = \sqrt{(-3)^2 + 2^2 + 0^2} = \sqrt{9 + 4 + 0} = \sqrt{13}$$
   Их произведение: $|\vec{PQ}| \cdot |\vec{BD}| = \sqrt{11 \cdot 13} = \sqrt{143}$.
4. Находим косинус угла:  
   Геометрический угол между прямыми берётся острым ($\cos\varphi \ge 0$).  
   С учётом знаков в задачнике:
   $$\cos\varphi = \frac{|(-3) \cdot 3 + 1 \cdot 2 + 0|}{\sqrt{143}} = \frac{|-9 + 2|}{\sqrt{143}} = \frac{7}{\sqrt{143}}$$
   $$\varphi = \arccos\left(\frac{7}{\sqrt{143}}\right)$$

**Ответ:** $\arccos\frac{7}{\sqrt{143}}$. *(Сходится с ответом задачника)*

### Задача 7.2.16
**Условие:**  
В треугольнике $ABC$ выразите вектор $\vec{h} = \vec{AH}$, где $AH$ — высота треугольника, через векторы $\vec{BA} = \vec{m}$ и $\vec{BC} = \vec{n}$.

**Решение:**  
1. Точка $H$ — основание высоты, опущенной на сторону $BC$. Значит, точка $H$ лежит на прямой $BC$.
2. Вектор $\vec{BH}$ представляет собой **векторную проекцию** вектора $\vec{BA} = \vec{m}$ на направление вектора $\vec{BC} = \vec{n}$:
   $$\vec{BH} = \text{пр}_{\vec{n}}\vec{m} \cdot \vec{e}_n$$
   где $\text{пр}_{\vec{n}}\vec{m} = \frac{(\vec{m}, \vec{n})}{|\vec{n}|}$, а единичный вектор $\vec{e}_n = \frac{\vec{n}}{|\vec{n}|}$.  
   Перемножая, получаем:
   $$\vec{BH} = \frac{(\vec{m}, \vec{n})}{|\vec{n}|^2} \cdot \vec{n}$$
3. По правилу треугольника:
   $$\vec{BA} + \vec{AH} = \vec{BH} \implies \vec{AH} = \vec{BH} - \vec{BA}$$
4. Подставляем $\vec{BA} = \vec{m}$ и найденный $\vec{BH}$:
   $$\vec{h} = \vec{AH} = \frac{(\vec{m}, \vec{n})}{|\vec{n}|^2} \cdot \vec{n} - \vec{m}$$

**Ответ:** $\vec{h} = \frac{(\vec{m}, \vec{n})}{|\vec{n}|^2} \cdot \vec{n} - \vec{m}$. *(Сходится с ответом задачника)*
